CineNova Master - Frontend Movie Recommendation Website

Files:
- index.html
- style.css
- script.js

How to run:
1. Keep all three files in the same folder.
2. Open index.html in Chrome, Edge, Safari, or Firefox.
3. For best results, use VS Code + Live Server.

Included features:
- Animated splash screen
- Login / signup UI
- Demo login
- Multiple profiles + profile creator
- Premium hero slider
- Search with suggestions
- Search by title, genre, cast, and director
- Genre filter
- Language filter
- Year filter
- Rating filter
- Sort by rating/year/name/duration
- Trending section
- Top 10 section
- New releases
- Personalized recommendations
- Mood-based recommendations
- Surprise Me
- Favorites
- Watchlist
- Recently viewed
- Continue Watching progress
- Movie detail modal
- Cast / director / writer
- Similar movies
- Trailer modal
- 1-5 star user rating
- Like/dislike preferences
- User reviews
- Share button
- Notifications UI
- Multiple color themes
- Responsive mobile navigation
- localStorage persistence
- Keyboard shortcut: press / to focus search

Note:
This is a frontend-only demonstration. Login is simulated with localStorage and is not secure authentication.
Movie imagery uses remote image URLs and trailers use YouTube embeds, so internet access is needed for those assets.
